This directory stores hdf5 files with diffsky parameter calibrations fit to cosmos data

c260710: fit to cosmos2020 0.4 < z < 2.5, and i < 25.5, grizyJHK data
cs261020: fit to cosmos2020 (0.4 < z < 2.5, and i < 25.5), included CHFT u*
          and sdss dr72 bright0 0.05 < z < 0.25, r < 17.58, ugriz data
