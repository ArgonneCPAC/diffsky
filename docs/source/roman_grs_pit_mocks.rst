Roman Galaxy Redshift Survey PIT mocks
======================================================

* Galaxies in the ``sdss_feniks_hizels_260710_09_07_2026`` mock populate the `Last Journey <https://arxiv.org/abs/2006.01697>`_ cosmological N-body simulation.
* Mock galaxies span a contiguous sky area of 2578.27 deg\ :sup:`2` across $0 < z < 4$, complete to $i < 25$.
* Columns include emission line strengths for Hα, Hβ, [OII], [OIII], and [SIII], plus photometry in all Roman and Rubin bands.

Documentation
-------------
The version of the documentation that pertains to this mock is
`diffsky.readthedocs.io v0.3.11 <https://diffsky.readthedocs.io/en/v0.3.11>`_.

Disk location
-------------
OpenCosmo-formatted data for this mock can be found here on NERSC:
``/global/cfs/cdirs/hacc/OpenCosmo/LastJourney/synthetic_galaxies/sdss_feniks_hizels_260710_09_07_2026``
